# OpenPOWER Linux Boot Platform

This directory contains the platform support files for booting Linux on
the OpenPOWER LCS (Linux Compliance Subset) processor generated by ISAComp.

## Overview

The platform implements a minimal SoC suitable for running NOMMU Linux:
- OpenPOWER LCS core (280 instructions)
- 64MB main memory
- 16550 UART for console
- Decrementer timer for Linux tick
- Simple interrupt controller

## Memory Map

| Address Range | Size | Description |
|---------------|------|-------------|
| 0x00000000 - 0x03FFFFFF | 64MB | Main RAM |
| 0xC0002000 - 0xC0002007 | 8B | 16550 UART |
| 0xC0004000 - 0xC000401F | 32B | Interrupt Controller |
| 0xC0006000 - 0xC000600F | 16B | SoC Syscon |

## Exception Vectors (Real Mode)

| Vector | Description |
|--------|-------------|
| 0x100 | System Reset |
| 0x200 | Machine Check |
| 0x300 | Data Storage |
| 0x400 | Instruction Storage |
| 0x500 | External Interrupt |
| 0x600 | Alignment |
| 0x700 | Program |
| 0x800 | FP Unavailable |
| 0x900 | Decrementer |
| 0xC00 | System Call |

## Files

### Peripherals
- `uart16550.sv` - 16550 UART (Linux ns16550a driver)
- `power_timer.sv` - Time Base and Decrementer
- `openpower_soc.sv` - SoC wrapper (combines CPU with peripherals)

### Boot Support
- `openpower_isacomp.dts` - Device tree source
- `boot/` - Boot ROM and build scripts (future)

### Tests
- `tests/linux_boot_tb.sv` - Verilator testbench for Linux boot

## Building

### Prerequisites

```bash
# Install Verilator
apt install verilator

# Install device-tree-compiler
apt install device-tree-compiler

# Install PowerPC cross compiler
apt install gcc-powerpc64le-linux-gnu
```

### Generate the Processor

```bash
cd /path/to/isacomp
python openpower/generators/generate_openpower_linux.py -o examples/verilog/openpower_linux
```

### Build the Simulation

```bash
cd examples/verilog/openpower_linux
verilator -Wall -Wno-fatal --cc --exe --build \
    linux_boot_tb.sv openpower_lcs_extmem.v \
    uart16550.sv power_timer.sv \
    -o Vlinux_boot_tb --top-module linux_boot_tb
```

### Build Linux Kernel

See the `boot/` directory for kernel build instructions.

For Microwatt-compatible build:
```bash
cd linux
make ARCH=powerpc CROSS_COMPILE=powerpc64le-linux-gnu- microwatt_defconfig
make ARCH=powerpc CROSS_COMPILE=powerpc64le-linux-gnu- -j$(nproc)
```

### Run Simulation

```bash
./obj_dir/Vlinux_boot_tb +kernel=vmlinux.bin +debug
```

## Compatibility

This platform is designed to be compatible with:
- Microwatt SoC architecture
- Linux NOMMU support for PowerPC
- Power ISA v3.0B (LCS subset)
